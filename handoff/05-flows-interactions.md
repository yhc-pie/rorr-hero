## 1. 큰 순간 → Boost → 카드 [공용]

```
순간 후보 감지(서버, 골드/홀로그램)
  → 큰 순간 알림 표시(빈도 상한 통과 시, 다른 모달 위 금지)
     ├─ [이 순간 Boost 준비] → Boost 상자(대상: 응원 팀 또는 참여한 즐겨찾기 선수)
     │     → 재화·금액 선택 → 주 버튼 1회(확인 대기 5초) → 2회
     │     → 서버: 잔액 확인·차감·카드 발급(순간당 1장, 멱등)·배지 단계 재계산·포인트(순간당 1회)
     │     → Boost 완료 연출 → 카드(신규 발급 또는 기존 카드 + "N 남음")
     ├─ [행운 박스 열기] → §2
     └─ [닫기] / 시간 초과 → 무산된 예고는 조용히 철회(무산률 계측)
```

| 단계 | 규칙 |
|---|---|
| 대상 결정 | 알림의 주 버튼은 **그 순간에 참여한 즐겨찾기 선수**가 있으면 그 선수 패널, 없으면 응원 팀 패널을 연다(4dfdb4b) |
| 순간·재화·금액 이어받기 | 이동 전 값을 `{재화, 수량, 시각, 대상 키}`로 보관 → **대상 패널 키가 일치할 때만** 소비. 다른 패널이 먼저 열려도 소비되지 않음 |
| 같은 순간 재Boost | 카드 추가 발급·포인트 추가 없음. 누적량만 배지 단계에 반영. 결과 화면은 카드를 다시 보여 주고 "Energy 누적 20 · 2단계까지 30 남음" |
| 누적 종료 | 그 순간의 Boost 창이 닫힐 때까지 누적 |
| 경기 종료 후 | 그 순간 카드 발급 불가. 컬렉션은 최종 단계로 저장 |
| Boost 확정 시점 | 의사 표시 즉시 vs 순간 발생 확인 후 — **미결(OI-13)**, 웹·확장 동일 로직 필수 |

## 2. 스폰서 행운 박스 [공용]

```
큰 순간 알림(파트너 경기 + 스폰서 범위, 지급 총량 남음)
  → 후원 줄 [행운 박스 열기]
     ├─ 비로그인 → 로그인 → 복귀
     ├─ 이미 연 순간 → 결과 칩만
     └─ 무대 열기 → 섞기 1.5s → 고르기 → 흔들기 1.1s → 결과
           ├─ 당첨(Spark 5 / 10): 지갑 적립 → [Spark N으로 이 순간 Boost]
           │     → Boost 상자(재화 Spark·수량 N 선택 상태)
           └─ 꽝: [Energy로 Boost] → Boost 상자(Energy·10 선택 상태)
  → 알림 줄의 박스 버튼 → 결과 칩
```

- 기회: 큰 순간 알림마다 1회. 응원 탭 등 다른 경로에서는 받지 않음(안내만)
- 당첨 Spark는 일반 Spark와 동일(순간 전용 아님, 광고 1일 한도와 별도 집계)
- 총량 소진 시 박스 미노출, 라벨만
- 서버 기록: 사용자·순간 ID·결과·시각·스폰서 계약 ID·확률표 버전

## 3. Energy 부족

| 제품 | 흐름 |
|---|---|
| 웹 | 주 버튼 → 토스트("Energy 10 필요 · 보유 4") → `#account/energy` + 상단 배너(부족분 · 돌아가기) + 충분한 최소 팩 강조 → 결제 완료 → "Boost로 돌아가기" → 원래 패널 응원 탭, 같은 순간·재화·금액 |
| 확장 | 토스트 + "rorr.club에서 충전" → 새 탭 웹 충전 → 패널 포커스 복귀 시 잔액 재조회 + "잔액을 새로 불러왔어요 · 이어서 Boost할 수 있어요" → Boost 시트·큰 순간 알림 중이었다면 시트를 Energy 선택으로 다시 엶 |

- 기준 잔액은 **유료 Energy만**. 보너스 Energy는 Boost에 쓸 수 없음(정책 v1.3 §1-1 안 C)

## 4. 비로그인 진입

- Boost·행운 박스·응원 반응·직접 질문은 로그인 필요
- 로그인 모달 → 완료 후 **같은 화면·같은 선택 상태** 복귀(확장은 웹 인증 경유 후 시트 유지)
- 로그인 요구 시점은 가치 체험 이후(확장 온보딩은 로그인 0회)

## 5. 확장 퀴즈 스트릭 [확장]

- 출제 → 응답(2지선다) → 마감(서버 시각, 결과가 어느 중계에도 보이기 전) → 결과
- 정답 +1 / 오답 0으로 / 미응답 유지 / 마감 전 이벤트 발생 → 무효("This one happened too fast. It won't count.")
- 큰 순간 예고와 겹치면 퀴즈 카드가 먼저 마감(Boost CTA와 화면 경쟁 금지)
- 재화를 걸거나 차감하는 요소 금지

## 6. 동작 타이밍 표

| 요소 | 트리거 | 동작 | 시간 | 이징 |
|---|---|---|---|---|
| 사이드 패널 | 열기·닫기 | 가로(모바일 세로) 이동 | 300ms | `--ease-standard` |
| 축소형 헤더 | 큰 이름이 상단 바 밖으로 | 8px 아래에서 떠오르며 나타남 | 200ms | ease |
| 토스트 | 표시 | 페이드·이동 | 300ms, 2.4s 유지 | ease |
| 두 번 누르기 | 1회 누름 | 버튼 문구 교체 + 테두리 타이머 링 | 5s | linear |
| 행운 박스 무대 | 열기 | 스크림 페이드 | 250ms | ease |
| 〃 | 섞기 | 3개 교차 | 1.5s | ease-in-out |
| 〃 | 고르기 대기 | 위아래 떠 있음(박스별 0.18s 지연) | 1.6s 반복 | ease-in-out |

- `prefers-reduced-transparency: reduce`(확장): 흐림·반투명 면을 불투명 면으로
