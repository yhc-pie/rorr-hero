# 08. 접근성·다국어·엣지 케이스·QA

- 작성일: 2026-10-17

## 1. 접근성

### 1-1. 초점·키보드

| 화면 | 규칙 |
|---|---|
| 전역 | 모든 조작 요소 `:focus-visible` 2px 링(`--focus-ring`). 마우스 클릭 시 링 미표시 |
| 사이드 패널 | 열 때 닫기 버튼에 초점 → 닫으면 연 요소로 복귀. 닫힌 패널 `inert` + `aria-hidden="true"`. Esc로 닫기 |
| 패널 초점 순서 | 즐겨찾기 → 닫기 → 탭(기록/응원) → 본문 → Boost 상자(재화 → 메시지 → − → 주 버튼 → + → ⓘ → 링크) |
| 큰 순간 알림 | Esc로 닫기. 알림이 떠도 초점을 빼앗지 않음(진행 중 입력 보호). 주 버튼은 Tab으로 도달 |
| 행운 박스 무대 | 모달(`role="dialog"` `aria-modal="true"`), 초점 가둠. 섞기 끝나면 첫 박스에 초점, ←→로 박스 이동, Enter·Space로 선택, Esc로 닫기 |
| 재화 선택 | 라디오 그룹 — ←→로 이동 |
| 스테퍼 | −/+ 끝 단계에서 `disabled` |

### 1-2. 이름·알림

| 요소 | 처리 |
|---|---|
| 아이콘 버튼(☆ × − + ⓘ) | `aria-label` 필수("즐겨찾기", "닫기", "금액 줄이기", "금액 늘리기", "배분 방식") |
| 두 번 누르기 | 1회 누름 후 `aria-label` = "5초 안에 한 번 더 누르면 Energy 10을 보내요" |
| 축소형 헤더 | `aria-hidden="true"`(제목 중복 방지) |
| 대상 줄 아바타 | `alt=""`(이름이 바로 옆 텍스트) |
| 토스트 | `aria-live="polite"` |
| 큰 순간 알림 | `role="status"`(골드) / `role="alertdialog"`(홀로그램, 초점 이동 없음) |
| 행운 박스 결과 | 결과 문장을 `aria-live="assertive"`로 1회 낭독("Spark 5개 당첨" / "이번엔 꽝이에요") |
| 확률 문구 | 시각적으로 작아도 스크린 리더에서 읽히는 텍스트로(이미지·의사 요소 금지) |
| 카운트다운 | 초 단위 낭독 금지 — 시작 시 1회만 "약 40초 뒤" |

### 1-3. 색·크기

- 본문 대비 4.5:1, 큰 글자·아이콘 3:1. 재화색은 숫자에만 쓰므로 굵기 700 이상 유지
- 라이트 테마 `--color-error-line` 미정(다크 값 그대로) → 대비 부족, 값 지정 필요
- 최소 글자 11px, 터치 높이 40px 이상(44px 권장). 확장 칩 28px은 터치 영역을 44px로 확장(v43)
- 동작 줄이기: `prefers-reduced-motion` — 반복·장식 정지, 단계 전환 50~100ms / 확장 `prefers-reduced-transparency` — 반투명 면 불투명화

## 2. 다국어 (KO·EN)

| 항목 | 규칙 |
|---|---|
| 문구 원본 | 웹 `KO` 사전(영문 → 국문)과 `LX(en, ko)` 호출이 문구 원본. 이식 시 i18n 키로 재작성 |
| 고유명 | 선수·팀명·재화명(Energy·Spark)·LwRC+는 번역 금지(원본 `translate="no"`) |
| 한국어 조사 | 받침 판별 함수(`JO()`)로 은/는·이/가·을/를·와/과 자동 선택. "은(는)" 같은 병기 금지 |
| 어순 | 국문 "**Faker** 응원" / 영문 "Cheering **Faker**" 처럼 강조 위치가 다름 — 문장 단위 키로 |
| 날짜 | 화면 표기는 로캘별, 저장·API는 ISO(YYYY-MM-DD, UTC) |
| 길이 | 영어가 대체로 길다. 버튼 한 줄 유지, 넘치면 문구를 줄임(예: 확장 시트 KO 문구 축약 사례) |
| 법적 고지 | 현재 한국어본만. EN 화면에 안내 문구 표시 |
| Muse 말투 | 국문 반말, 수치 낭독 금지, 상대 비하·선수 판정 금지(말투 가이드) |

## 3. 엣지 케이스

- 아래는 구현 규칙이다. 데모 원본에 없는 처리(서버 거절·느린 응답 등)도 포함하므로 원본에서 찾지 말고 이 표대로 구현

| 상황 | 처리 |
|---|---|
| 라이브 순간 없음 | 대상 줄 둘째 줄 생략, 선수 칩 미표시, 카드 미발급(경기 중이 아니면) |
| 사진 없는 선수(비제휴·미확보) | 이니셜 원. 비제휴 선수는 닉네임 자체를 쓰지 않음 |
| 긴 이름 | 축소형 헤더: 이름 줄바꿈 없음, 보조 문구만 줄임표 |
| 양쪽 팀 모두 응원 팀 | LIVE 중립 "내 응원 팀 2팀 경기", Boost 상자에 응원 대상 팀 명시 |
| 같은 순간 재Boost | 카드 1장 유지, 누적만 증가, 결과에 "N 남음" |
| 3단계 도달 후 재Boost | "최고 단계" 표시, 남은 양 안내 없음 |
| 경기 종료 직후 | 열린 Boost 상자는 전송 시 서버 거절 → "경기가 끝나 이 순간 카드는 발급되지 않아요" |
| 행운 박스 총량 소진 | 박스 미노출, 후원 라벨만 |
| 같은 순간 두 탭·웹+확장 동시 | 박스·카드·포인트는 서버 멱등. 늦게 온 요청에 기존 결과 반환 |
| 오프라인 | 상단 오프라인 바, 라이브 해설 "일시 정지 · 마지막 갱신 {시각}", Boost 주 버튼 비활성 |
| 느린 응답 | 주 버튼 진행 표시, 3초 이상이면 안내, 재시도는 같은 멱등 키 |
| 로그인 중 순간 종료 | 복귀 시 상자 유지하되 순간 칩 해제 + 안내 |
| 미성년 | 순위·하이라이트 기본 OFF, 광고성 메시지 없음, 결제 한도 하향, 퀴즈 상금 수령 연령 제한(확장) |
| 보너스 Energy만 있음 | "Boost에는 유료 Energy만 쓸 수 있어요" + 충전 |
| 확장: 비지원 호스트 | S1 평시(채팅) |
| 확장: 매칭 실패 | 경기 선택 목록 → 지연 보정 1탭 |
