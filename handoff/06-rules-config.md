# 06. 규칙·서버 판정·설정 변수

- 작성일: 2026-10-17 · 근거: 정책 v1.3(`docs/policy/boost-economy-policy.md`)
- 이 문서는 정책을 **구현 단위로 옮긴 요약**이다. 조항 해석·문구가 다르면 정책 원문이 우선이며, 각 행에 정책 조항(§)을 표기한다

---

## 1. 재화 (§0·§1·§1-1)

| 규칙 | 구현 |
|---|---|
| Energy(유료)·Spark(무료)는 별개 | 잔액·아이콘·색 분리 표시, 합산 금지, 상호 전환 불가 |
| Energy는 유료·보너스로 분리 | 잔액 표시 "⚡ 유료 120 · 보너스 30 (RORR 장식 전용)". **Boost는 유료 Energy만**, 보너스는 RORR 장식만(`BONUS_ENERGY_SCOPE=rorr_deco`) |
| 가입 보너스 | 첫 RORR 장식 출시 전 미지급(`SIGNUP_BONUS_START`) |
| 패키지 혜택 | 보너스 추가분 폐지 → 단가 할인(상한 10%, 계단식). 팀 배분은 **할인 전 정가 환산액** 기준 |
| 사용 순서 | RORR 장식: 보너스 먼저 → 유료. 같은 종류 안에서는 만료 빠른 묶음부터 |
| 유효기간 | 유료 5년 · 보너스 1년 · Spark 시즌 |
| Spark 획득 | 웹 광고 월(광고 1편당 5, 1일 10편) · 확장 퀴즈 주간 상금 · 스폰서 행운 박스 — 경로별 한도 별도 집계 |
| Spark 사용처 | Boost만 |
| AI 질문 | Energy 사용처 아님. 직접 입력 질문은 로그인만 필요 |
| 환불 | 7일 이내 미사용 전액·수수료 없음 / 이후 수수료 5%·최소 1,000원 / Boost·장식에 쓴 Energy 환불 불가. 상세: `docs/specs/refund.md` |
| 부정 이용 | 잔액이 음수가 되면 Boost 차단 |

## 2. 팀 구분 (§2·§2-1·§3)

| 기능 | 파트너 팀(현재 T1) | 비제휴 팀 |
|---|---|---|
| Energy Boost | ✅ | ❌ |
| Spark Boost | ✅ | ✅(유일 수단) |
| 카드 | 파트너 에디션 | RORR 모먼트 카드 |
| 팀 로고·색·별칭·선수 닉네임·사진 | 협약 범위 내 | ❌(텍스트 닉네임 포함 금지) |
| 팀명 | 협약 범위 내 | 경기 식별 문장 안 1회·비강조 |
| 팀 내 서포터 순위 | 응원 포인트(Energy·Spark 동일) | Spark 기준 "비공식 팬 순위", 팀명 텍스트만 + "팀에 전달되지 않음·제휴 없음" |
| 배분 안내 | "RORR는 Boost 수익의 일부를 파트너 팀과 나눠요" + ⓘ(정산 기준). **비율은 팀 공개 동의 시에만** | "팀에 분배되지 않음" + 필수 고지 원문 |
| 스폰서 후원 줄·행운 박스 | ✅(계약 범위) | ❌ |
| 메시지 발송(팀 명의) | ✅(RORR 대리 발송) | ❌ |

- **배분 비율 값은 화면·클라이언트 번들·API 응답에 넣지 않는다**(서버 정산 설정에만). 비율은 팀별 협약값이며 현재 대외 비공개
- 금지 문구(전 팀): "팀에 전달", "응원금", "송금", "후원금", "선수에게 전달됩니다", "팀을 돕는다", "공식"(협약 허용 전), "레어"
- 비제휴 팀 필수 고지(그대로 사용): "현재 제휴·정산 약정이 체결되지 않은 팬덤 테마입니다. 본 이용은 RORR가 제공하는 디지털 부스트 기능이며, 특정 팀에 대한 금전 지급 또는 제휴를 보장하지 않습니다."
- 전 화면 공통 독립 서비스 고지: "An independent fan companion. Not endorsed by Riot Games." / "비공식 독립 서비스이며 팀·리그·Riot Games가 후원·승인하지 않습니다."

## 3. 카드·배지·포인트 (§4·§4-1·§4-2·§5-3)

| 규칙 | 구현 |
|---|---|
| 카드 발급 | 경기 진행 중 순간에 Boost 시 1장. 키 = (사용자, 순간 ID). 웹·확장 같은 컬렉션 |
| 등급(테두리) | 순간 크기: 실버 / 골드 / 홀로그램 — 서버의 순간 등급 |
| 배지 | 같은 순간 누적량, 재화별: Energy 10~49=1 · 50~99=2 · 100+=3 / Spark 5~19=1 · 20~49=2 · 50+=3 |
| 에디션 | 발급 시점 협약 상태로 저장(`edition`), 렌더는 저장값 기준 |
| 기념 에디션 | 파트너 선수만, 달성일 ±3일(`MS_WINDOW_DAYS`), 기념일당 1장, 등급 없음, 축하 순번 저장 |
| 응원 포인트 | 순간당 1회 +20 · 크기 보너스 +10/+30/+60 · 연속 응원 경기당 +10(최대 +100, 경기당 첫 Boost에 1회) · 수량·광고 0 P |
| 무작위 | 등급·배지·연출 무작위 금지. 예외: 행운 박스(판촉 추첨, 카드·배지·포인트에 직접 반영 없음) |
| 복수 응원 팀 | 포인트·카드·연속 응원은 팀별 분리 적립. 양팀 응원 경기는 "그 순간을 만든 팀"에 적립, 화면에 "T1 응원" 명시 |

## 4. 알림·메시지 (§5-4·§5-5·§5-7)

| 규칙 | 구현 |
|---|---|
| 경기 중 큰 순간 | 푸시 없음. 웹은 사이트 열린 동안만, 확장은 패널 안 + 닫힘 시 아이콘 배지 |
| 빈도 | 웹 배너 3분 1회·팝업 경기당 1회 / 확장 `EXT_HEADSUP_MIN_GAP` |
| 경기 시작 알림 | 응원 팀만, 옵트인, 10분 전 1회(+시작 시 선택), 같은 팀 하루 2회, **한 사용자 한 채널**(확장 → 웹 푸시 → .ics) |
| 메시지 분류 | 서비스 공지(동의 불필요·광고 금지) / 내 소식(기본 켜짐) / 팀·선수 소식(옵트인) / 광고(옵트인) |
| 광고 표기 | 제목 앞 "(광고)"/"(Ad)", 전송자·수신 거부 방법. 야간(21~08시)은 별도 동의 |
| 대상 선정 | 응원 활동 기준만. **결제 여부·금액·잔액 기준 금지**, 최소 인원(`MSG_MIN_AUDIENCE`) 미만 금지 |
| 미성년 | 광고성 메시지 발송 금지, 순위·하이라이트 노출 기본 OFF |
| 기록 | 동의·철회 일자, 2년마다 재확인, 발송 요청자·검수자·대상 조건·문안 버전 |

## 5. 스폰서 행운 박스 (§6-1 B)

| 항목 | 구현 |
|---|---|
| 노출 | 파트너 경기 + 스폰서 계약 범위 + 지급 총량 남음 + 큰 순간 알림 표시 중 |
| 확률 | `SPONSOR_BOX_ODDS`(꽝 75 / Spark 5 20 / Spark 10 5, 임시). 화면에 상시 공개, 확률표 버전 기록 |
| 1회 제한 | (사용자, 순간 ID) 단위 1회, 로그인 필요 |
| 결과 | 서버 결정. 박스 위치와 무관. 당첨은 지갑 적립(일반 Spark) |
| 총량 | `SPONSOR_BOX_POOL` 소진 시 박스 미노출 |
| 측정 | 홀드아웃 비교 — ① 그 순간 Energy Boost율 ② 같은 경기 다음 큰 순간 Boost율 ③ 다음 파트너 경기 재방문율 |
| 철회 기준 | `SPONSOR_BOX_KILL_DROP`(홀드아웃 대비 Energy Boost율 2주 연속 하락 임계치) 등 — 대시보드에 지표 필요 |

## 7. 데이터 기록 (최소 필드)

| 레코드 | 필드 |
|---|---|
| Boost | 사용자, 순간 ID, 경기·세트·게임 시각, 대상(팀/선수), 응원 팀, 재화, 수량, 유료/보너스 구분, 채널(web/ext), 고지 문구 버전·노출 시각, 멱등 키, 생성 시각 |
| 카드 | 사용자, 순간 ID, 등급, 에디션(발급 시점), 팀, 주인공 선수(확장 '내 선수' 규칙), 재화별 누적량·배지 단계, 발급 시각 |
| 기념 에디션 | 선수 ID, 기록 종류·수치, 달성일, 축하 순번, 발급 시각, 달성 경기 ID |
| 행운 박스 | 사용자, 순간 ID, 스폰서 계약 ID, 확률표 버전, 결과, 지급 Spark, 시각, 홀드아웃 여부 |
| 알림 노출 | 사용자, 순간 ID, 종류(골드/홀로그램), 채널, 노출·클릭·닫기 시각, 무산 여부 |
