## 2. 브레이크포인트

원본은 21종(420~1599px)이 섞여 있음. 사용 빈도: 760(38) · 640(18) · 860(16) · 1100(6). 이식 시 아래 5단으로 정리하고, 원본의 소수 구간은 화면 실측으로 흡수한다.

| 단계 | 범위 | 주요 변화 |
|---|---|---|
| `xs` | ≤ 420px | 행운 박스 3개 크기 84×92px·간격 6px, 박스 제목 20px |
| `sm` | ≤ 640px | 큰 순간 배너: 후원 메시지 숨김·박스 버튼 30px·스폰서 이름 숨김 / 표 열 축약(`.c-x` 숨김·`.m-only` 표시) |
| `md` | ≤ 760px | **사이드 패널 → 하단 시트**(높이 86vh, 위 모서리 16px, 끌기 손잡이 40×4px), 서브 페이지 1단 |
| `lg` | ≤ 1100px | 홈 오른쪽 열(`.pside`)·순위·팀 블록이 아래로 이동, 히어로 내부(`.hx-in`) 1단 |
| `xl` | ≥ 1520px (오른쪽 레일 ≥ 1600px) | 서브 페이지 좌우 레일(`.siderail`) 표시, 1520~1599px은 왼쪽만 |

## 3. 선수·팀 사이드 패널

| 항목 | 데스크톱(> 760px) | 모바일(≤ 760px) |
|---|---|---|
| 형태 | 오른쪽 고정 패널 | 하단 시트 |
| 크기 | 폭 560px(비교 모드 `min(560px, 96vw)`) | 폭 100%, 높이 86vh |
| 등장 | `translateX(102%)` → 0, 300ms `--ease-standard` | `translateY(102%)` → 0 |
| 상단 바 | 높이 56px, 좌 패딩 20px. [유형 라벨 / 축소형 헤더] · 즐겨찾기 ☆ · 닫기 × | 같음 + 끌기 손잡이 |
| 스크롤 | 패널 본문(`#ip-body`)이 스크롤 | 같음 |
| 닫힘 상태 | `inert` + `aria-hidden="true"`, 그림자 제거 | 같음 |

- 축소형 헤더 규칙은 `04-components.md` §2 참조
