# 07. 웹·확장 비교와 정합

- 작성일: 2026-10-17 · 원본: rorr-extension `docs/15-web-ext-gap.md`, `docs/13-design-review.md` §20~24, 확장 `handoff/`(v45)
- 원칙: **웹은 찾아보는 곳, 확장은 보는 곳**. 계정·재화·카드·포인트·순위는 같고, 차이는 시청 경험

---

## 1. 의도된 차이 (유지)

| 영역 | 웹 | 확장 |
|---|---|---|
| Muse(서하) | `#muse` 30초 체험 | 메인 캐릭터(VRM 3D)·감정 5단계·빠른 반응 |
| 퀴즈 스트릭·주간 Spark 상금 | 순위 열람만 | 참여·상금(확장 전용 혜택은 이것뿐) |
| 질문 | 일반 Q&A | 라이브 맥락(경기·세트·게임 시각) 자동 첨부 |
| 큰 순간 알림 도달 | 사이트 열린 동안, 탭 제목·파비콘 | 패널 안, 닫힘 시 아이콘 배지 |
| 큰 순간 알림 빈도 | 3분 간격·방문당 3회 | 더 높게 허용(`EXT_HEADSUP_MIN_GAP`) |
| 경기 시작 알림 | 웹 푸시·.ics | 확장 알림(`chrome.notifications`) |
| 충전·환불·결제·광고 월·알림함·전체 순위·LwRC+ 상세·블로그·자랑하기 | 직접 | 웹 링크로 위임 |
| Energy 부족 | 토스트 → 충전 화면 → 응원 탭 복귀 배너 | 토스트 + 웹 충전 링크 → 복귀 시 잔액 재조회·시트 재개 |
| 카드 주인공 '내 선수' | 미적용 | 적용 — 경기 시작 때 서하가 "오늘 누구 응원해?"로 묻고 Boost 시트 1줄 "카드 주인공 · ★ Faker 우선 ⓘ" |
| 선수 지정 Boost | 선수 패널 응원 탭 · T1 팀 응원 탭 "이 교전의 선수 응원하기" 칩 | 순간 Boost + 내 선수 주인공 규칙 |
| 본문 글자 | 17px | 14px(패널 360px) |

## 2. 반드시 같아야 하는 것

- 카드 규칙(등급·배지 누적·에디션·무작위 없음) · 응원 포인트 · 최소 단가(Energy 10·Spark 5) · 스테퍼 단계 · 두 번 누르기(5초)
- 비제휴 팀 표기·필수 고지 · 배분 안내 문구(비율 미표기) · 금지 문구
- 후원 라벨 · 행운 박스 확률·결과·결과 후 Boost 연결(당첨 → Spark 선택, 꽝 → Energy 선택)
- 기념 에디션 표시(경기 중 포함) · 재Boost 시 카드 다시 보여 주기 + "N 남음"
- 동작 줄이기 대응

## 3. 공용 컴포넌트 (한 번 만들어 두 곳에서)

| 컴포넌트 | 웹 | 확장 | 공용화 방법 |
|---|---|---|---|
| 모먼트 카드·기념 에디션 카드 | 패널·컬렉션·완료 연출 | 시트·Me 탭 | 같은 렌더러(크기만 prop) — 확장은 F-08 AC "동일 렌더링" |

## 5. 사용자 검증 질문 (확장 15 §3)

- 확장 → 웹 충전 → 확장 복귀 후 Boost 완료율
- 설치 동기: 퀴즈 스트릭 vs 시청 경험
- 웹 '선수 응원'과 확장 '순간 응원 + 내 선수 주인공'의 차이 인지 여부
- 방법: 사용성 테스트 6명, "큰 순간 Boost → Energy 부족 → 충전 → 재Boost" 과제 완료율·이탈 지점
