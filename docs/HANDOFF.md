## 2. 옮기지 않을 것 (대체 대상)

- **샘플 데이터 엔진**: `LGS`, `DB`, `mkRnd`, `hashStr` 기반 경기·선수·순위·메시지 생성 → API로 대체
- **데모 상태 저장**: `localStorage`의 `rorr-bx`(잔액·카드·포인트·내역), `rorr-rem`, `rorr-ma`, `rorr-notify` → 서버 상태
- **KO 번역 사전**: `const KO={영문 문장: 국문}` + DOM 순회 치환(약 1,050개) → i18n 키 체계로 재작성. 문구 원본으로만 참조
- **결제·광고·인증 데모**: 토스트만 띄우는 충전, 로그인 모달 데모, 광고 월 재생 시뮬레이션

## 3. 화면 상태 클래스 → 라우트 매핑

원본은 해시 라우팅 SPA이며 `body` 클래스로 화면 모드를 바꿈.

| body 클래스 | 의미 | 원본 경로 | Next.js 대응 |
|---|---|---|---|
| (없음) | 홈 | `#` | `/` |
| `pagev` | 서브 페이지 모드(히어로 축소·헤더 solid) | `#match/{id}` `#rank` `#spark` `#stats` `#wrc` `#blog` `#blog/{slug}` `#about` `#contact` | 각 라우트의 레이아웃 |
| `acct` | 계정 페이지 | `#account/{tab}` (energy, boost 등) | `/account/[tab]` |
| `chatting` | AI 대화 화면 | `#chat` | `/chat` |
| `ip-open` | 선수·팀 사이드 패널 열림 | `#player/{name}` `#team/{id}` | 패널 상태(병렬/인터셉트 라우트 권장) |
| `ip-cmp` | 패널 비교 모드 | `#compare/...` | 패널 내부 상태 |
| `museing` | Muse 30초 체험 | `#muse` | 모달 |
| `authing` / `onboarding` | 로그인·온보딩 모달 | — | 모달 상태 |

## 4. CSS 현황 (태그 시점)

- CSS 약 240KB, `!important` 216개, 같은 셀렉터 2회 이상 정의 419개
- 기능 추가 때마다 파일 하단에 덮어쓰는 구조 → **위쪽 정의를 옮기면 틀림**. 실측값 기준으로 이식
- 반응형 구간 13개: 520 · 560 · 600 · 640 · 760 · 860 · 900 · 980 · 1000 · 1100/1101 · 1519/1520px
  - 사용 빈도 상위: 760(20) · 860(14) · 640(6) · 1100(6)
- 기본 본문: 17px / 줄간격 1.55, 폰트 Pretendard → Apple SD Gothic Neo → Malgun Gothic
- 사이드 패널 폭 560px, 메인 콘텐츠 최대 폭은 1220·1520px 구간에서 변경
