# RORR 사이트 미구현·데모 동작 현황

- 작성일: 2026-10-17 · 기준: rorr-hero `index.html` (이번 커밋)
- 점검 방법: 주요 화면 20곳의 버튼·링크 전수 클릭 점검(상태 변화 유무 자동 판정) + 코드 검토
- 전제: 현재 사이트는 서버 연결이 없는 **단일 HTML 데모**. 외부 요청(`fetch`) 0건, 모든 상태는 브라우저 저장소(localStorage)에만 저장

## 1. 이번에 고친 동작 오류

| 위치 | 문제 | 조치 |
|---|---|---|
| 푸터 이용약관·개인정보·환불 정책 | 링크가 `#`(이동 없음) | 법적 고지 페이지 3종 신설·연결 (`#terms` `#privacy` `#refund`, 조항 단위 링크 `#terms/a16`) |
| 로그인 창 "약관에 동의" 문구 | 링크 없음, KO 번역 누락 | 이용약관·개인정보 처리방침 링크, KO/EN 분리 |
| 계정 › 결제 내역 하단 | "환불 정책은 유료 출시 전 게시" 임시 문구 | 환불 정책 링크로 교체 |
| 경기 페이지 "크롬에 추가" | `href="#"` — 눌러도 반응 없음 | 크롬 웹스토어 링크 연결 |
| 경기 페이지 "기념 Boost 보내기" | 선수 페이지만 열리고 Boost 대상 미선택 | 선수 응원 탭 + 기념일 자동 선택 |
| Boost 완료 연출 | 카드가 새로 나올 때만 컷인 재생. 같은 순간 재Boost·순간 미선택 Boost는 링만 표시 | 모든 Boost에 컷인 재생(재Boost·순간 미선택은 0.85초 축약판, "한 번 더 응원!") |

## 2. 화면은 있으나 데모로만 동작 (서버·외부 연동 필요)

| 영역 | 현재 동작 | 실제 구현에 필요한 것 |
|---|---|---|
| 로그인·가입 | 아무 값이나 통과, 가입 시 보너스 Energy 토스트 | 인증 서버, 소셜 로그인(Google·Apple·Microsoft) |
| 소셜 계정 연결·해제 | "Apple connected" 토스트만 | OAuth 연동 |
| 비밀번호 재설정 | "재설정 링크를 보냈어요" 토스트만 | 메일 발송 |
| 계정 삭제 | 확인 메일 발송 토스트만 | 삭제 확인 메일·유예·파기 처리(개인정보 처리방침 §7) |
| 로그인 기기 목록 | 샘플 3대, 로그아웃은 목록에서만 제거 | 세션 관리 |
| Energy 충전 | "토스페이먼츠 데모, 결제 없음" 토스트 후 잔액 증가 | 토스페이먼츠 결제·웹훅 |
| 결제수단 변경 | "결제 수단을 여는 중…" 토스트만 | PG 결제수단 관리 |
| 영수증 | "영수증을 내려받았어요" 토스트만 | 영수증·현금영수증 발급 |
| 환불 신청 | **화면 없음** (정책 페이지는 이메일 접수 안내) | 환불 견적·신청 화면, API (`docs/specs/refund.md`) |
| 광고 월 Spark | 시청 시뮬레이션 후 Spark 5 지급 | GAM 웹 보상형 광고·서버 검증·일일 한도 |
| Ask RORR | 규칙 기반 데모 답변 | AI 모델·경기 데이터 연동, 질문 과금(Energy 1) |
| 경기·지표 데이터 | 샘플(T1 외 선수명은 가상), 일정은 오늘 기준 상대 날짜 | 경기 데이터 파이프라인, LwRC+ 산출 |
| Boost·카드·포인트·순위 | 이 브라우저에만 저장, 다른 팬·기기와 공유 안 됨 | 서버 원장·순위 집계 |
| 함께 Boost 수·응원 메시지 피드 | 샘플 + 시간 따라 증가하는 연출 | 실시간 집계, 메시지 검수 |
| 응원 메시지 신고·답장 | 신고는 토스트만, 답장은 로컬 표시 | 신고 큐·검수 |
| 서포터 순위 | 샘플 팬 + 내 순위 계산 | 서버 순위, 익명 설정 반영 |
| 알림 설정 | 설정 저장만, 실제 발송 없음 | 웹 푸시·이메일·확장 알림 채널 |
| 알림함 | 샘플 메시지 5건 | 메시지 발송·검수 시스템(정책 §5-7) |
| "열리면 알림 받기"(리그·비제휴 팀) | 토스트만 | 구독 저장·발송 |
| 경기 예측 투표 | 이 브라우저에만 저장 | 집계 |
| Muse 30초 체험 | 샘플 장면 재생 | (마케팅용 — 유지) |
| 공유 이미지 | 동작(이미지 저장) | 공유 링크·OG 이미지 |

## 4. 출시 전 확정이 필요한 값 (화면·문서에 `[대괄호]`로 남아 있음)

- 약관·처리방침·환불 정책 시행일
- 개인정보 보호책임자 성명·직책, 위탁사(클라우드·메일·AI), 국외 이전 내역과 근거
- 미성년자 월 결제 한도, Spark 유효기간(시즌 종료일)·1일 획득 한도
- 이용 제한 이의 제기 기간(약관 제25조), 미접속 회원 처리 방식
- 화면 내 환불 신청 기능 출시 시점(그 전까지 이메일 접수)
- 익스텐션 퀴즈 공식 규칙(Official Rules) 웹 게시 페이지 — 정책상 상금 지급 전 게시 필수, 아직 없음
- 사업자 정보 대표자 표기(푸터 "조만수")와 회사 소개 "Mike" 표기 관계 확인

## 5. 점검에서 오탐으로 판단한 항목
