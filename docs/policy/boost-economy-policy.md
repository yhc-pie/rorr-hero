## 0. 용어

| 용어 | 정의 |
|---|---|
| **Energy (⚡)** | 돈으로 충전하는 유료 재화. 환불·청약철회 대상 |
| **Spark (✦)** | 광고 시청으로만 얻는 무료 재화. 구매·환불·양도·현금화 불가 |
| **Boost** | 경기 중 순간에 팬이 보내는 응원 행위. Energy 또는 Spark를 소모 |
| **모먼트 카드** | Boost를 보낸 순간을 기록한 디지털 카드. 거래·양도 불가 |
| **파트너 팀** | RORR와 서면 협약(MOU 이상)을 맺은 팀. 현재: **T1** (협약에 선수 닉네임·IP 포함 확인, 2026-10-15. "공식" 표현 허용 여부는 협약 문안 확인 필요) |
| **미계약 팀** | 협약이 없는 모든 팀 |
| **LwRC+** | RORR 선수 기여도 지표 명칭(공식). "야구 wRC+처럼 100=리그 평균" 설명은 허용 |

## 1. 재화 규칙

| 항목 | Energy ⚡ | Spark ✦ |
|---|---|---|
| 획득 | 결제 충전 | **RORR 웹사이트 광고 월**에서 보상형 광고 시청 |
| 획득 한도 | 월 결제 한도(성인 기본, 미성년 낮게) | 1일 획득 한도(값 미정) |
| 사용처 | Boost, 유료 장식 | **Boost만** |
| Energy↔Spark 전환 | 불가 | 불가 |
| 양도·현금화 | 불가 | 불가 |
| 환불 | 미사용분 환불(약관 명시) | 해당 없음 |
| 유효기간 | 약관에 따름 | 시즌 단위(값 미정) |
| 팀 배분 | 파트너 팀만, 산식 공개 | **없음** (파트너 팀 포함, 2026-10-15 확정) |

**UI 규칙**
- Energy와 Spark는 **아이콘·색·잔액 표시를 분리**한다. 한 숫자로 합산 표시 금지.
- Boost 버튼은 어떤 재화가 차감되는지 표시한다.


### 1-1. Energy 환불 (2026-10-15 결정 · 법률 검토 전)

| 구분 | 규칙 |
|---|---|
| 청약철회 (구매 후 7일 이내) | 미사용 유료 Energy 전액 환불, **수수료 없음**. 일부 사용 시 미사용 유료분만: 결제 금액 × (미사용 유료 Energy ÷ 구매 유료 Energy) |
| 7일 경과 후 잔액 환불 | 미사용 유료분 환불 가능, **환불 수수료 청구** (요율·최소 금액은 변수 `REFUND_FEE_RATE`·`REFUND_FEE_MIN`, 값 미정) |
| Boost에 사용한 Energy | 환불 불가(사용 즉시 제공 완료). 구매 화면·Boost 확인 화면에 사전 고지 필수, 고지 기록 보관 |
| 보너스 Energy (가입·패키지 추가분) | 환불 대상 아님. **유효기간 1년** |
| 유료 Energy 유효기간 | 5년 |
| 사용 순서 | **보너스 Energy 먼저**, 같은 종류 안에서는 만료일이 빠른 묶음부터 |
| 미성년자 | 법정대리인 동의 없는 결제는 사용분 포함 취소 가능. 동의 확인 절차·월 결제 한도 |
| 탈퇴·서비스 종료 | 탈퇴 전 잔액 환불 안내. 서비스 종료 시 30일 전 공지 후 미사용 유료분 전액 환불(수수료 없음) |
| 환불 방법·기한 | 원결제수단 취소 우선, 불가 시 계좌 환급. 접수 후 3영업일 이내 |
| 부정 이용 | 구매·철회 반복, 결제 취소 후 사용 등은 이용 제한. 잔액이 음수가 되면 Boost 차단 |
| Spark | 무상 재화로 환불 대상 아님 |
| 고지 위치 | 충전 화면(청약철회 기한·방법), Boost 확인 화면(취소 불가), 환불 정책 페이지, 이용약관 |

- 정산 연동: 파트너 배분(§8)은 **Boost로 사용된 유료 Energy만** 대상. 미사용·환불·결제 취소분은 배분 없음. 정산 후 취소(미성년 취소 등)는 다음 정산에서 차감 — 협약에 차감 조항 필요.

## 4. 모먼트 카드

| 항목 | 규칙 |
|---|---|
| 획득 | **경기 진행 중** 순간에 Boost(Energy 또는 Spark)를 보내면 즉시 지급. **웹사이트·Chrome 확장 프로그램(Muse 사이드 패널) 모두 동일하게 지급** (2026-10-15 변경). 경기 종료 후에는 그 순간에 카드 발급 불가. 한 순간당 카드 1장(같은 순간 재Boost 시 추가 발급 없음). 기념일(마일스톤) Boost는 포인트만 적립, 카드 미발급 |
| 명칭 | "모먼트 카드"로 통일. "레어 카드" 등 구매·뽑기를 연상시키는 표현 사용 금지 |
| 판매 | 판매하지 않음. 현금 가치 없음(응원의 기록이며 자산이 아님) |
| 안내 노출 | 카드가 보이는 화면(메인 팬덤 라이브·내 Boost·히어로·Boost 완료 화면)에 "판매하지 않음 · 경기 중 Boost 시 웹·확장 프로그램 어디서든 획득" 안내와 모먼트 카드 안내 글 링크 표시 |
| 카드 등급(테두리) | **순간의 크기**로 결정: 일반=실버 / 승부처=골드 / 결승·역대급=홀로그램 |
| 서포터 장식 | **Boost 양**으로 결정(1~3단계, 작은 배지). Spark는 1단계까지, Energy는 2~3단계 |
| 무작위 | **없음**. 등급·장식 모두 확정 규칙 |
| 거래·양도 | 불가 |
| 카드 내용 | 경기, 세트, 시각, 순간 설명(자체 작성), 승리확률 변화, 함께 Boost한 팬 수, 내 Boost 시점 |
| 시각 자산 | RORR 자체 디자인(타임라인·숫자·Muse)만. **챔피언 일러스트·게임 화면·중계 캡처 금지**. 예외: 파트너 에디션의 팀 표장·선수 사진(§4-1) |
| 카드 데이터 | 발급일, 발급 당시 에디션(파트너/일반), 팀, 경기·순간 ID를 카드에 저장 |
| 미계약 팀 카드 | 사실 정보만, 선수 닉네임 없음 ("24:10, 바론 교전 역전"), 팀 색상 없음 |
| 공유 | 공유 이미지에 날짜·기준·출처·비제휴 고지 포함 |

- **확장 프로그램 설치 명분** (2026-10-15 블로그 기준): 카드·포인트·순위 혜택은 웹과 동일하게 두고, 차이는 **시청 경험**으로 안내 — ① 중계(YouTube·치지직·SOOP·Twitch) 옆 사이드 패널, ② 탭 전환 없이 순간 Boost(순간을 놓치지 않음), ③ 시청 중 큰 순간 예고(웹은 RORR 탭이 열려 있을 때만), ④ 질문에 라이브 맥락 자동 첨부. 확장 전용 추가 혜택은 **현재 두지 않음** (2026-10-15 결정).
- **비파트너 경기 카드 = RORR 모먼트 카드** (2026-10-15): 파트너 에디션과 같은 카드 틀(등급 → 비주얼 영역 → 경기·순간 → 소유자)을 쓰되, 팀 로고·색상·선수 닉네임·사진 대신 **RORR 엠블럼 + 승리확률 스윙 그래픽**(RORR 자체 데이터 시각화)과 RORR 남보라 배경을 사용. 팀명은 경기 식별용으로 1회만.

### 4-1. 파트너 에디션 카드 (상태: 논의 중 · 협약 확정 전)

| 항목 | 규칙 |
|---|---|
| 적용 대상 | 파트너 팀 경기의 순간에 발급된 카드 |
| 추가 요소 | 팀 색상, 공식 로고, 순간의 주인공 선수 닉네임·포지션, 공식 선수 사진(배경 없는 컷) |
| 등급 규칙 | 테두리(순간의 크기)·배지(Boost 양) 규칙은 일반 카드와 동일. 에디션은 디자인 레이어이며 등급·희소성에 영향 없음 |
| 에디션 판정 | **발급 시점 기준**. 협약 유효 기간 중 발급 = 파트너 에디션, 그 외 = 일반 카드 |
| 계약 종료 후 | 기존 발급분은 파트너 에디션 그대로 유지(과거 제작물). 종료일 이후 발급분은 일반 카드로 지급 |
| 표시 기준 | 화면은 카드에 저장된 에디션 값으로 렌더링. 현재 협약 상태로 다시 판정하지 않음 |
| 컬렉션 | 시즌 세트(예: T1 2026 시즌 선수 5명) 진행률 표시 가능. 무작위 없음 |
| 제작 원칙 | 로고·선수 사진은 구단이 제공한 공식 파일만 사용. RORR가 로고·얼굴을 임의로 제작·생성하지 않음 |
| "공식" 표기 | 협약이 허용할 때만 "공식 파트너 에디션", 그 외에는 "파트너 에디션" |

**협약에 반영할 조항**
1. 존속 조항: 협약 기간 중 발급된 카드의 팀 표장·선수 사진은 협약 종료 후에도 계속 표시할 수 있다.
2. 선수가 이적·은퇴해도 1을 적용한다(선수 개인 초상권 동의 포함).
3. 협약 종료 후 신규 제작은 중단하되, 기존 카드의 표시와 공유 이미지 생성은 계속 허용한다.
4. 1~3을 확보하지 못하면, 협약 종료 시 기존 카드도 중립 디자인으로 전환한다는 규칙을 사전에 이용자에게 고지한다.

## 5. 순위·과시

| 위치 | 노출 | 규칙 |
|---|---|---|
| 공개 Boost 순위 페이지 | 팬덤 순위(파트너만), 팀 내 서포터 순위, 팬덤 목표 | 금액 대신 **포인트** 표시 |
| 메인 "팬덤 라이브" 구역 | 팬덤 성과, 이번 주 모먼트 카드, 서포터 하이라이트, 응원 메시지 | 개인 결제액·금액 순위 노출 금지. 상대 팬덤 비하 구도 금지 |
| 경기 페이지 | 이 경기 Boost 현황, 상위 서포터 3~5명, 집단 목표 | |
| 프로필 > 내 Boost | 내 순위, 내역, 배지, 공개 설정, 사용 한도 | |

- 기본 순위 기준은 **참여**(카드 수, 연속 응원, 큰 순간 참여). 금액 기반은 보조.
- **익명 설정**을 존중(메인 포함 모든 곳).
- **만 19세 미만**은 메인 하이라이트 노출 기본 OFF, 결제 한도 낮게.
- 응원 메시지: 욕설 필터 + 신고 기능 필수.
- 팀 간 팬덤 비교: 파트너 팀 3곳 이상일 때 공개. 그 전에는 비파트너 팀명·순위 비노출.

### 5-1. 응원 메시지 반응·답장 (2026-10-15 결정)
- 메시지는 Boost와 함께 작성 → 팀·경기·순간 맥락을 함께 저장하고 표시(팀 칩, 순간 칩, 대상 선수).
- 비파트너 경기 메시지: 팀 로고·색상·선수 닉네임 없이 "오늘의 N경기 · 세트 시각"만 표시. 메인 기본 필터는 파트너(T1), "전체 경기"는 선택.
- 반응: "나도 응원" 1종. 로그인 필요, 메시지당 1회.
- 반응 수는 서포터 순위 포인트에 **미반영**(맞반응·다중 계정 어뷰징 방지). 반영 시 일일 상한 필수.
- 답장: **정해진 답장 칩만 허용**(예: GG, 다음 경기도 같이!, 이 순간 최고, 끝까지 간다). 자유 텍스트 댓글은 보류 — 검수 체계 확보 후 경기 페이지·팬 월부터 검토.
- 신고: 기능은 유지하되 "⋯" 메뉴 안에 배치(전면 노출 금지).

### 5-2. 복수 응원 팀·양팀 응원 (2026-10-15 결정)
- 포인트·카드·연속 응원은 **응원한 팀별로 분리 적립**. 한 번의 Boost가 두 팀에 동시에 적립되지 않음. 순위도 팀별(한 사람이 T1 127위이자 GEN 2,400위 가능).
- **대표 팀**: 응원 팀 중 1개(기본 = 처음 고른 팀, 응원 팀 설정에서 변경). 팬덤 라이브는 대표 팀 기준으로 열리고, 응원 팀이 2개 이상이면 팀 전환 칩 제공.
- **비파트너 응원 팀**: 칩은 팀명 텍스트만(로고·색상 없음). 내 포인트·카드는 보여주되 팬덤 순위·시즌 목표·서포터 하이라이트는 비공개.
- **양쪽 팀 모두 응원 팀인 경기**: LIVE 표시는 중립("내 응원 팀 2팀 경기"). 양쪽 Boost 모두 허용하며, 각 Boost는 그 순간을 만든 팀(승리확률이 움직인 쪽)에 적립. Boost 화면에 응원 대상 팀("T1 응원") 명시.
- 두 팬덤을 맞세우는 대결 구도(게이지·VS 비교)는 만들지 않음(상대 팬덤 비하 금지, 팀 간 비교는 파트너 3곳 이상부터).
- 자랑하기 이미지는 팀 1개 단위로 생성.
- 응원 메시지 기본 필터 = "내 응원 팀"(응원 팀 전체), 선택 = "전체 경기".

### 5-3. 응원 포인트 산식 (2026-10-15 사이트 반영)
| 항목 | 포인트 | 규칙 |
|---|---|---|
| 순간에 Boost 1번 | +20 P | Energy·Spark 동일. 재화 종류·수량과 무관. **같은 순간에 여러 번 보내도 1번만 적립** |
| 순간의 크기 보너스 | +10 / +30 / +60 | 실버 / 골드 / 홀로그램(카드 테두리와 같은 기준) |
| 연속 응원 보너스 | 경기당 +10 (최대 +100) | 연속 응원 경기 수 × 10. 경기당 첫 Boost에 1회 적립. 한 경기 쉬면 초기화 |
| 결제 수량·광고 수 | 0 P | 순위 미반영. 수량은 카드 배지 단계에만 표시 |
- 예시: 골드 순간 Boost = 20 + 30 = 50 P. 순위 페이지 "포인트 계산법 ⓘ"에서 같은 내용 공개.
- 미결: Spark Boost 비용(5 Spark 제안)·Spark 1일 한도 — 한 경기의 큰 순간을 Spark로도 따라갈 수 있는 수준으로 설정(§8).

### 5-4. Muse 큰 순간 알림 (2026-10-15 사이트 반영)
- 방식: **웹 푸시 미사용**. RORR 사이트를 열어 둔 동안만, 어느 페이지에 있든 표시.
- 골드 순간 → 상단 배너(Muse 반신 + 순간명 + 카운트다운). 홀로그램 순간 → 화면 중앙 팝업(Boost 완료 연출과 같은 틀, Muse 중심).
- 탭 신호: 다른 탭에 있을 때 탭 제목 앞 "(⚡ 곧 바론)" + 파비콘 점.
- 빈도 상한: 배너 3분에 1회, 팝업 경기당 1회, 다른 모달(결제·Boost 완료·로그인) 위에는 띄우지 않음.
- 사용자 설정: 골드+홀로그램 / 홀로그램만 / 끄기 (내 Boost > 공개 설정).
- 대상 경기: 응원 팀 경기 우선. 팝업 CTA는 "이 순간 Boost 준비"(Boost 패널 열기)이며, 자동 차감 없음.
